# Проект: Большая антикварная библиотека "A million books"

## Предметная область
Проект охватывает предметную область автоматизированного библиотечного дела и умного учета редкой литературы. Система автоматизирует каталогизацию книжного фонда по авторам и жанрам, учет зарегистрированных читателей, а также временную выдачу печатных экземпляров.

## Решаемая проблема
Система решает проблему централизованного учета уникального книжного фонда, предотвращает утерю редких изданий, отслеживает сроки возврата книг и упрощает поиск литературы для читателей.
